📡 REST API Endpoints

This API provides structured information about KoliBri examples that can be used by AI agents.

GET /mcp/health

Backend status and sample index metadata

GET /mcp/samples

List of all available samples (optional filter with ?q=filter)

GET /mcp/sample?id=sample/button/basic

Path and source code of a specific sample

GET /mcp/concepts

List of Markdown-based concept documents

GET /mcp/concept?id=concept/README

Retrieve a specific concept document including its Markdown source

Hinweis: Die Indizes werden im Buildprozess erzeugt. Ein manuelles refresh ist in Deployments nicht verfügbar.

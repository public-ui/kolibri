VS Code Extension - Test & Demo

Status

Plugin erfolgreich geladen

Diese Testseite demonstriert die Funktionalität des "Convert to KoliBri" VS Code Plugins.

✨ Hauptfunktionen

  • Automatische Konvertierung von HTML zu KoliBri Komponenten
  • Syntax-Highlighting für alle KoliBri Komponenten
  • Live-Vorschau der konvertierten Komponenten
  • Automatische Barrierefreiheit (WCAG 2.1 AA)
  • Multi-Framework Support (React, Angular, Vue, Svelte)
  • TypeScript & JSX Integration
  • Intelligente Theme-Integration

Unterstützte Komponenten

Button

Primäre und sekundäre Button mit verschiedenen Varianten und States

Input

Text-, Email-, Passwort- und weitere Input-Typen mit Validierung

Select

Dropdown-Komponente mit Single- und Multi-Select Support

Table

Responsive Datentabelle mit Sorting und Paginierung

Modal

Dialog-Fenster mit customizablem Content und Actions

Tooltip

Kontext-sensitive Hinweise mit verschiedenen Positionen

Code Beispiel

Beispiel einer konvertierten Button-Komponente:

<kol-button   _label="Click me"   _variant="primary"   _on-click="handleClick"> </kol-button>

🚀 Verwendung

  1. 1. Öffne eine HTML-Datei in VS Code
  2. 2. Markiere den zu konvertierenden HTML-Code
  3. 3. Öffne die Command Palette (Cmd+Shift+P)
  4. 4. Gib "Convert to KoliBri" ein
  5. 5. Fertig! Der Code wird konvertiert

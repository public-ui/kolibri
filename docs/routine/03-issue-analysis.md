# Schritt 3 – Issue analysieren

Lies den Issue-Body und alle Kommentare vollständig. Beurteile:

- Ist das Problem klar beschrieben und reproduzierbar?
- Ist die Ursache im Code lokalisierbar?
- Ist eine Lösung mit überschaubarem Aufwand möglich?

Wenn das Issue unklar ist, nicht reproduziert werden kann oder zu groß ist: Hinterlasse einen freundlichen Klärungskommentar auf Englisch, benenne konkret was fehlt, und schließe die Routine mit Schritt 8 (Statusbericht) und Schritt 9 (Review) ab. Kein PR.

Melde: Issue-Titel, Autor, Alter, Komplexitätseinschätzung (niedrig / mittel / hoch) und ob Umsetzung oder Klärungskommentar folgt.

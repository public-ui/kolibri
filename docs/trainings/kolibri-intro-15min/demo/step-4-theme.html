Das Markup unten ändert sich nie.

Nur die Zeile, in der das Theme registriert wird.

Die Buttons sind echt – einmal draufklicken.

Zwei Ebenen, zwei Geschwindigkeiten:
• Theme wechseln heißt: ein anderes Paket registrieren. Das passiert einmal beim Start der Anwendung – Farben, Schriften, Abstände, Radien, alles kommt aus dem Theme. Genau so macht es auch die offizielle KoliBri-Beispielanwendung.
• Tokens überschreiben geht sofort und ohne Neuladen. Drei CSS-Zeilen, und sie wirken quer durch den Shadow DOM – dafür sind CSS-Custom-Properties da. 
// Theme registrieren – eine Zeile entscheidet über das ganze Erscheinungsbild
import { DEFAULT } from '@public-ui/theme-default';
await register(DEFAULT, defineCustomElements);

// Oder das Corporate Design des Bundes:
import { KERN_V2 } from '@public-ui/theme-kern';
await register(KERN_V2, defineCustomElements);

// Nur einzelne Stellschrauben? Reines CSS, wirkt sofort:
:root {
  --kolibri-color-primary: #cc006e;
  --kolibri-border-radius: 14px;
  --kolibri-font-size: 18px;
}

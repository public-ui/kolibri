Bausteine, zusammengesetzt.

Karte, Formular, Felder, Button – nichts davon weiß voneinander, und trotzdem passt es.
Nichts davon steht im Markup oben:
• Die Zeile „Formular-Felder, die mit einem Sternchen (*) gekennzeichnet sind, sind Pflichtangaben." setzt kol-form von sich aus – in der Sprache der Anwendung.
• Das Sternchen am Label ist CSS content: '*' / '': sichtbar ein Stern, für den Screenreader nichts. Kein „Stern Stern Stern" beim Durchhören.
• Der Zeichenzähler läuft doppelt: sichtbar aria-hidden, daneben eine aria-live-Region mit ausformuliertem Text.
• Jeder Button ist mindestens 44 × 44 px groß – nachmessen mit dem Röntgenblick.
Eine Stolperfalle für den Vanilla-Einstieg: In HTML gibt es kein camelCase. Aus der Prop _maxLength wird das Attribut _max-length, aus _hasCounter wird _has-counter. Wer _maxLength="120" ins HTML schreibt, bekommt keinen Fehler – nur keinen Zähler. In React/JSX schreibt man dagegen wieder _maxLength.

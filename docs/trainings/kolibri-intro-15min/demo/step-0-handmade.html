Frage ans Publikum: Das Feld ist im Fehlerzustand. Was fehlt?
Antwort: aria-invalid="true". Ohne das Attribut sagt kein Screenreader, dass dieses Feld fehlerhaft ist – der Fehlertext wird zwar vorgelesen, aber das Feld gilt als in Ordnung.

Und das ist erst ein Feld. Vier IDs, drei ARIA-Attribute, ein role="alert", ein aria-hidden am Sternchen – alles von Hand, alles still brechbar.

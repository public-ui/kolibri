15′ KoliBri Web Components – Einsteigerschulung

Die Demo in fünf Schritten

Jeder Schritt ist eine eigene Seite. Vor und zurück über die Leiste oben.

  • 0 · Ein barrierefreies Feld – von Hand Der Schmerz. Vier IDs, drei ARIA-Attribute, ein stiller Fehler.
  • 1 · Die erste Komponente Drei Zeilen Setup, ein Tag – und das Feld ist fertig.
  • 2 · Insel im Bestand KoliBri in einer alten Seite mit aggressivem CSS und nativem Formular.
  • 3 · Komposition & Röntgenblick Karte, Formular, Felder – und was KoliBri ungefragt richtig macht.
  • 4 · Das Theme wechseln Gleiches Markup, anderes Haus. Und Tokens live überschreiben.
  • 5 · Dasselbe in React Gleiche Props, andere Klammern.
Vor dem Vortrag: Diese Demo läuft vollständig offline aus dem Ordner vendor/. Fehlt er, einmal node fetch-vendor.mjs im Ordner kolibri-intro-15min ausführen. Starten mit einem beliebigen statischen Server, zum Beispiel npx http-server -p 8080 demo – file:// reicht nicht, weil ES-Module über HTTP geladen werden müssen.

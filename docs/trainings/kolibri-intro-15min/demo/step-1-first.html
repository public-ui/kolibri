Noch nichts passiert – tippt ins Feld oder klickt einen Button.

Zwei Konventionen, die sofort auffallen:
1. Alle Props beginnen mit einem _ – so kollidieren sie nie mit nativen HTML-Attributen.
2. _label ist Pflicht. Eine KoliBri-Komponente ohne Beschriftung gibt es nicht – Barrierefreiheit ist hier kein Schalter, den man vergessen kann.

Die Varianten (primary, secondary, danger, ghost) sind übrigens keine feste Liste im Code, sondern kommen aus dem Theme. Merken – das wird Schritt 4.

Und noch eine Konvention: Verhalten hängt an _on – einem Objekt mit Callbacks, das per JavaScript gesetzt wird: feld._on = { onBlur: … }. Dasselbe gilt für _msg und _touched: Das sind Properties, keine Attribute. Deshalb steht im Markup oben kein Fehler – der entsteht erst, wenn ihr einen macht.
